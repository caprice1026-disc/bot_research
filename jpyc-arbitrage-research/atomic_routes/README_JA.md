# JPYC の原子的な裁定ルート：実在候補と未検証項目

2026-10-20 16:03–16:06 UTC の公開データ調査。実売買・コントラクト配備は行っていません。詳しいアドレス・出典と取得結果は [調査原文](README.md) と JSON を参照してください。

## 結論

同じチェーン上で借入資産に戻り、元本・借入料・ガス・MEV 費用を引いて余りが出る経路なら、原子的な裁定は成立し得ます。しかし **日本円の銀行償還は同一オンチェーントランザクション内の返済経路にはできません**。二つの円建てトークンがともに1円を目指すことは、トークン間を実際に1対1交換できることを意味しません。

今回見つかった有力な「接続経路の候補」は、Polygon native USDC → 現行 JPYC → 別プールの native USDC。同一コントラクトのペアについて、GeckoTerminal で4本の Uniswap v4 プールを確認しました。**黒字を実測した結果ではありません**。同一ブロックの往復 quote、正しい pool key・hooks・fee・有効 tick 流動性の確認が必要です。TVL と出来高は約定見積もりの代わりになりません。

## 別の円建て資産を使う場合

- Jarvis jJPY の公式資料には Polygon 上の合成資産 mint/redeem 経路があります。ただし担保は USDC.e、表示手数料は0.3%で、現行の停止状態・限度額・oracle 鮮度・実見積もりは未検証です。銀行への1円償還請求権と同一ではありません。
- 既存 Curve の jJPY/JPYC や GYEN/JPYC/jJPY プールで確認した JPYC は、現行の償還型ではなく旧前払式トークンでした。名称だけで経路を接続してはいけません。
- GYEN 発行体の公式告知では、2026-11-11 が当初償還期限の wind-down 対象です。継続的な戦略の前提に流動性・償還存続を置けません。現行 JPYC と GYEN の直接交換経路も、今回の確認範囲では未確認です。

## 資金の借入と費用

Flash loan は一時的な資金を提供するだけで、利益そのものの源泉ではありません。Aave の手数料は変更可能で、資料上の初期値を現在の Polygon の確定値として使用していません。公開 RPC の fee getter 呼出しは HTTP403 で停止したため、現在値は null のまま保存しています。拒否を他の接続先で迂回していません。

収益判定は、最終借入資産の受取 − 借入元本 − 借入料 − ガス相当額 − tip/MEV費用。swap fee と price impact は数量別の連続見積もりに既に含めるため二重控除しません。条件不成立で revert してもガスは失われます。クロスチェーンのブリッジや銀行償還は通常の単一チェーン原子的返済とは分けて検討します。
