# JPYC：LP単体と片側レンジ＋償還の比較

## 結論

- **LP単体**は手数料収入を得られるが、手数料だけを利益と呼べない。逆選択、在庫の偏り、為替変動、レンジ外の無収入、出入りのガスを差し引く必要がある。
- **割安側の片側USDCレンジ＋JPYC償還**は、Makerとして「安いJPYCの指値買い＋手数料」を行う構造。JPYCが溜まったらLPを引き出し、1円償還することで戻り売りを防ぐ。今回の固定注文再生では、全部JPYCになるまで待つより、一部転換で引き出す条件の成績が良かった。
- ただし約24時間・1プールの条件付き反実仮想であり、実現利益や期待年利ではない。実際に全員が同じ注文量で取引し続ける保証はなく、裁定競争や価格変化への他参加者の反応は再現していない。外部取引は観測されたgross inputを固定したexact-input注文として再生し、元取引のmin-out、price limit、ルーターの再経路選択や取引中止は再現していない。

## データ・共通条件

2026-10-19 11:35:00 UTC～2026-10-20 11:13:20 UTC（日本時間20:35～翌20:13:20）。Polygonの現行JPYC/native USDC、Uniswap v4、120 Swap、29 ModifyLiquidity、285観測点。pool IDは 0x4643e3152a6ea3957e087cefbba74a1c628aa643e6b8a0edfae23a5796dde012。token0=USDC（6桁）、token1=JPYC（18桁）、tick spacing=10、hooksなし。初期FXは158.1090078834232円/USDC。

100/1,000 USDC相当の同じ初期円予算を比較。資金調達・送金・円→USDC再調達コストはゼロ。署名・実売買なし。初期JPYCを含むLPの調達は1円/JPYC仮定で、実際の初期swapを行った計算ではない。LP単体の対JPY現金利益にはこの仮定の影響があるため、同じ初期トークンを保有するベンチマークも併記した。

総swap手数料625 pipsの全額をLPに渡さず、各価格区間で protocol=floor(gross input×125/1,000,000)、残りをLP用とした。自己ポジションがactiveな区間だけ、自己L/全active LでQ128 fee growthを積算し、引出時にfloorした。自己LPを追加した価格・流動性のまま以後の外部swapを再生。初期価格を毎回復元せず、外部LP変更も反映する。手数料は自動複利化しない。

ガスは実測receiptでなく明示的感度仮定。base=mint25万gas、burn/collect30万gas、当該block base fee＋30 gwei。high=50万/60万gas、＋100 gwei。POL円価格は既存の後方参照系列。ガスは別途POL準備金から払う想定で、損益には全額控除するが、ポジション予算とは別にPOLが必要。token approval、初回専用コントラクトデプロイは含まない。実際の償還条件・上限・営業日・送金コストはこのモデル外。

## LP単体：中心レンジを固定して保有

下表は1,000 USDC相当、base gas。期間末にburnする。レンジは初期プール価格の周囲、tickへ外側丸めした実幅なので、±0.1%指定は実際には30 ticks幅となる。初期50:50固定ではなく、その時の価格と境界に必要なUSDC/JPYC比率でmintする。

|---|---:|---:|---:|---:|---:|
|±0.1%|62.01円|2.06円|+343.39円|+331.14円|+5.86円|

1円評価は「LP単体で現金化した利益」ではない。終値markも、そのシナリオの限界プール価格を使った評価で、実際に全量swapした清算価格ではない。各シナリオで終値が変わるため、外生共通終値による投資成績比較とも異なる。最狭レンジは期間末にほぼ全額JPYCとなり、active観測点は121/285。狭いほど無条件に儲かるわけではない。中幅・広幅は285/285観測点でactiveだったが、観測点比率を正確な稼働時間比率と取り違えない。

同一初期バスケットとの差は「在庫変化による差＋手数料−ガス」。これは連続的にリバランスする理想ポートフォリオとの比較ではなく、厳密なLVR測定ではない。手数料APRの単純年率換算は行わない。

## 片側レンジ＋償還：安くなった時だけJPYCを買う

初期はUSDCだけを入れる。内部価格P=JPYC/USDCなので、現在より高いPのレンジを使う。JPYC売りでPが上昇するとUSDCがJPYCに変わる。「JPYC円価格が低い側」と「内部tickが高い側」は同じ方向。

0.5%割安から0.6%割安までの購入を指定した結果、tick丸め後の初期FX換算レンジは **0.993959145～0.994953552円/JPYC**。買値上限0.995円を超えないよう開始tickを切り上げた。FX基準は開始時のまま固定。ドル円が変われば実際の円建て割安度も変わるため、このレンジはJPYに対する永続的な固定指値ではない。

引出判定は約5分ごとの観測点で行う。全量転換または初期USDCの25%以上がJPYCに転換したら、ポジション全体をburn。残USDCとUSDC手数料はその時のFXで円資金に戻し、JPYCとJPYC手数料は1円償還の未収金へ。償還0/1/24時間後にだけ現金へ戻す。次の観測点以降、価格がレンジより下で、初期予算の99%以上の現金が戻っている時だけ同一レンジへ再mintする。1観測点で複数回の無限再投資はしない。保有中に価格が戻ればJPYC→USDCへ逆変換する。終了時は比較のため未完了ポジションも強制burnする。

利益判定のための最適な売買トリガーを探索したものではない。固定の転換率で引き出すルールであり、ガス込みで毎回利益を保証するルールではない。

|引出条件|償還待ち|mint/burn回数|手数料|ガス|JPY現金比NAV利益|USDC保有比NAV利益|期末未収金|
|---|---|---:|---:|---:|---:|---:|---:|
|全量転換|0h|1/1|317.21円|2.06円|+542.06円|+511.54円|0円|
|全量転換|1h / 24h|1/1|317.21円|2.06円|+542.06円|+511.54円|39,620.91円|
|25%転換|0h / 1h|2/2|74.30円|3.40円|+1,004.45円|+973.93円|0円|
|25%転換|24h|1/1|31.13円|1.50円|+575.14円|+544.62円|62,247.45円|

全量転換条件は一度も全量転換していない。結果は期末の部分転換状態を強制引出して1円償還する前提。25%条件も実際の約定は観測間に25%を超えて進むため、ちょうど25%で抜けた計算ではない。

24時間待ちの未収金は利益ではなく**元本を含む償還予定額**。表の利益は現金＋未収金−初期資金−gasであり、口座で使える現金利益ではない。0.75%/1%割安では今回の注文列に約定がなく、USDC保有比は約−2.06円（gasのみ）。JPY現金比だけなら約+28.46円になるが、これは主に為替変動でLP収益ではない。

## なぜ片側＋償還に可能性があるか

単純swap買いはLP/プロトコル手数料を支払う。Maker方式は売り手がレンジに到達した時だけJPYCを買い、LP手数料を受け取る。一方、待機資金の機会費用、未約定、既存LPとの分配、取引サイズの制約、逆戻りを防ぐ引出タイミングがある。「同じ購入量がより安く必ず取れる」わけではない。

1円償還を本当に利用できるなら、LPの片方向在庫化は必ずしも損ではなく、割安購入を完了した状態になり得る。逆に償還が遅れる/止まる、JPYではなくUSDC側が動く、旧前払JPYCを誤用する等では成立しない。この利益の出どころは割安で売る外部参加者の流れと手数料であり、リスクゼロの新規価値創造ではない。

次に検証する価値があるのは、長期・複数の相場期間、共通の外部FX/JPYC評価、ガスreceipt、実際の償還制限、競合裁定反応、期末の実際の清算見積もり。今回の数字で大きな資金を入れる判断はしない。
