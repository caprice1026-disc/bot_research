# JPYC 償還裁定の利益源泉：実ログと限定再生による考察

対象は 2026-10-19 20:35:00 ～ 2026-10-20 20:13:20 JST、Polygon の USDC/JPYC Uniswap v4 プール。以下はこの 1 窓・1 プールの証拠であり、全 JPYC 市場の恒常的な需要を代表しない。

## 1. 経済的な源泉

1 JPYC を DEX で 1 円未満の総費用で取得し、1 円で償還する差額が原資になる。発行体が 1 円を払い戻すこと自体は、既に発行済みの債務を消す履行であり、裁定利益のために発行体が損をして補助しているという意味ではない。

直接の交換相手は LP のプール在庫。割安な売値の提示が続く背景として、JPYC を売って USDC 等へ換える需要、LP の価格調整の遅れ、FX 変化、裁定参加者の資金・償還処理・競争上の制約が考えられる。LP は手数料を得る一方、適正価値より安く JPYC を引き渡す機会損失を負いうる。LP の総損益は手数料、保有資産、入出金、評価基準次第であり、この裁定利益と同額の「LP の確定損」を今回計算したわけではない。

ユーザーが挙げた「円 → JPYC 発行 → JPYC を売って USDC → DeFi」という経路なら、JPYC に売り圧力を加える。売る人には速さ・使いやすさ等の価値があり、JPYC が割安でも取引を選ぶ場合がある。同じ方向のフローは、送金受取人の USDC 化、資産リバランス、別プール・別チェーンとの裁定、報酬資産の換金などでも発生する。動機は Swap ログの符号だけでは確定できない。

## 2. 実ログで確認できた売り超過

Uniswap の Swap イベントは呼出者側の token delta。負が支払、正が受取。currency0 は USDC、currency1 は現行 JPYC。

| 方向 | 件数 | USDC 側数量 | JPYC 側数量 |
|---|---:|---:|---:|
| USDC → JPYC（JPYC 買い） | 51 | 159,598.122331 支払 | 25,349,285.394592 受取 |
| JPYC → USDC（JPYC 売り） | 69 | 242,030.826670 受取 | 38,481,949.480433 支払 |
| トレーダー差引 | 120 | **82,432.704339 受取** | **13,132,664.085841 支払** |

つまり Swap による純フローだけなら、プールへ約 1,313 万 JPYC が入り、約 8.24 万 USDC が出た。JPYC の売り需要が優勢という観測で、on-ramp 仮説と整合する。ただし本人の発行履歴・前後の送金・DeFi 入金先は追跡しておらず、新規オンランプ資金だとは断定しない。LP 出し入れは別で、14 回追加、11 回削除、4 回 liquidity delta=0 のイベントがあった。

## 3. 開始時点の割安在庫と、継続する需要を分ける

開始時点のプール spot は 158.71926879 JPYC / USDC。参照 USDC/JPY は 158.10900788 円なので、1 JPYC 当たり約 **0.996155 円、−0.3845%**。これは手数料・注文 impact 前の spot。実際の quote は総 swap fee 0.0625% と impact 込みで評価している。

同じ参照方法による全 285 点の spot は約 0.994333 ～ 0.998798 円、期末約 0.994893 円。CoinGecko の集計 JPYC 価格をプールの約定価格に代用した結果ではない。ただし USDC/JPY は集計参照価格であり、取引可能な銀行・交換業者の為替ではない。

追加の条件除去実験（初期約 158,109 円、1,000 USDC 固定、即時 1 円償還、基準ガス、5 分 1 注文、自己 impact 維持）：

| 外部条件 | 回数 | モデル純利益 |
|---|---:|---:|
| 元モデル：外部 Swap・LP 変更・参照 FX 全て使用 | 202 | 27,248.88 円 |
| 外部 Swap なし、LP 変更と時系列 FX は残す | 116 | 17,541.75 円 |
| 外部 LP 変更なし、Swap と時系列 FX は残す | 218 | 28,076.32 円 |
| 外部 Swap・LP 変更なし、時系列 FX は残す | 130 | 18,852.65 円 |
| 外部 Swap・LP 変更は使用、FX を初期値に固定 | 206 | 69,983.95 円 |
| 外部 Swap・LP 変更なし、FX も初期値に固定 | 126 | 37,277.66 円 |

最後の行は開始時点の割安な在庫を自分で買って是正していく実験。126 回を超えると同じ固定サイズの注文で利益条件を満たさなくなり、鞘は無限には残らない。ガスの円換算は元の時系列を残している。

外部 Swap を除くと元モデルより約 9,707 円少ないことは、売り超過フローがモデルの利益機会を増やしたという感度を示す。ただしこれを「利益の何%が新規売り手由来」と分解してはいけない。LP・FX・注文時刻・数量選択は相互作用するため、各差額の足し算による因果寄与率ではない。初期固定 FX のケースの方が利益が大きいことも、今回の為替経路が利益を一方的に生んだわけではないことを示す。

## 4. 17% という資金収益率の解釈とモデルの強い仮定

元モデルの自己取引は累計 202,000 USDC（取得費約 3,198.66 万円、受取約 3,201.41 万円、ガス約 169 円）。約 15.81 万円を 202 回回せる仮定が資本収益率を大きくする。取得総額に対する純利益は約 **0.0852%** であり、「1 回 17% の鞘」ではない。

自己回転額 202,000 USDC は観測された外部 Swap の USDC 側総額 401,628.949001 の約 **50.3%**、外部の USDC→JPYC 買い 159,598.122331 の約 **126.6%**。市場に対して無視できる小さい追加注文とはいえない。

固定観測入力の反実仮想では、自己買いで JPYC が高くなるため、既存 JPYC 売り手の USDC 受取は実際より約 497.373174 USDC 増加、既存 JPYC 買い手の受取は約 70,240.740865 JPYC 減少した。これらは同じ入力を強制して再生した結果で、現実に他の人がこの条件を受け入れるという証拠ではない。注文取消・slippage 上限・別ルート・競合 bot・LP 調整が起きれば数量や利益は変わる。

したがって収益源泉の有力な説明は、**既存の割安在庫＋JPYC 売りフロー＋償還・市場間移動の摩擦**。回転を速める仮定はその鞘を少ない元本で取り出す仕組みであって、新しい価値を無から作るものではない。1 円償還の条件を満たせる競合が増えると、通常は価格が手数料・ガス・資金拘束費を考慮した裁定境界へ近づき、同じ高収益が続くとは限らない。

## 5. 追加検証すべきこと

- 売り手が JPYC 新規発行者なのか、既存保有者・別チェーン・別プールの裁定者なのか。各取引の前後を追い、本人の動機とは分けて分類する。
- 発行・償還の実際の待ち時間、最低額、上限、手続、銀行営業日。今回の即時・無制限仮定とは別に検証する。
- DEX 外の実行可能 USDC/JPY のスプレッド・手数料を含む完全な循環。今回ユーザー指定で調達・送金コストは除外している。
- 競合と LP の反応、slippage 上限、MEV、失敗取引を含む前向き Paper 観測。
- 複数日・複数プールで売り超過と利益機会が継続するか。この 1 日の機会を年率化しない。
