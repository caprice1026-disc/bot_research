# 検証方法・列の意味

## 外生的な単位換算

参照株式価値を十億米ドルで表すと、実株1株型の価格 p、外部資料に基づく株数 N に対して、

`V = p × N / 10^9`

を使う。これは負債を含む企業価値EVではない。参照株数10億株型は数値上 `V = p` だが、Lighterの総株数仮定とAsterの希薄化後参照株数仮定は契約上同義と断定しない。比較に用いる USDT、USD、USDC 等の1対1換算も別の仮定である。

価格に合わせて N を推定せず、価格比のフィット、平均差の除去、100基準化、欠損補間を行わない。XYZ ANTなど実株1株型は株式クラスと株数の一致が必要で、条件未確認の市場を無条件に合算しない。[契約仕様の比較](CONTRACTS.md)。

同時刻・同価格種別での Lighter プレミアムは `100 × (P_L / P_A − 1)`。前段で使った Aster の相対差 `100 × (P_A / P_L − 1)` とは分母が異なり、単に符号を反転した値ではない。

## 板・数量・費用

Asterを買い、Lighterを同じ数量 q だけ売る。共通数量を0.01単位で切り下げたうえで、予算、最低数量、最低注文額、両側の十分な深度を確認する。数量が成立しなければそのサイズを執行可能と扱わない。これは板・metadataに基づく検査で、実注文の受付確認ではない。

方向別VWAPは `Σ(価格 × 消費数量) / q`。入口差は `100 × (Lighter売りVWAP / Aster買いVWAP − 1)`。入口に差があっても、先物2脚を持った時点で差額が確定利益になるわけではない。

固定数量の2市場・往復価格損益は、

`PnL_price = q × [(A_exit_sell − A_entry_buy) + (L_entry_sell − L_exit_buy)]`

とし、4脚それぞれの約定額に適用手数料率を掛けて控除する。基本ケースは Aster taker 0.000125、Lighter metadata taker 0。Lighter 0.0003 は任意感応度。報告された損益率は片側Aster買い基準であり、両市場の証拠金合計に対する収益率ではない。報告の丸め値から数量・精密な分母を復元しない。

即時4脚反対売買は観測板で同方向の入口と逆方向の出口を計算した静的評価。注文による板の変化、遅延、キュー、部分約定、価格保護をすべて再現するものではない。

## 出口の感応度

最終標本の中値を `m_A, m_L`、平均を `c = (m_A + m_L) / 2`、差を `d = m_L − m_A` とする。残す差の割合を `r = 1, 0.5, 0` として、

`m_A' = c − r d / 2`、`m_L' = c + r d / 2`

を想定する。現在の方向別VWAPと中値の差を出口にも保持する。結果には基本手数料を含みFundingを含めない。中値平均・摩擦・数量の固定は感応度計算の仮定であり、実際の出口を予測しない。

## Funding の符号とcash

正のFunding率で買いが支払い、売りが受取りとなる規約の下では、固定数量 q の各精算時刻 j について概念的に、

`C = Σ_j [q × Index_L,j × f_L,j − q × Mark_A,j × f_A,j]`

となる。ただし、Lighter履歴の rate/direction/value がこの符号付き f とどのように対応するか、各 timestamp がどの区間に対応するかを正式に確定する必要がある。Aster側も精算時Markが必要。現行計算式を過去へ逆適用しない。

報告の30日率合計は一定等額建玉を仮定した条件付き率比較であり、固定数量cash計算と区別する。直前の足や現在Markを精算価格と決めつけない。[Fundingの確認点](LIMITATIONS.md)。

## 歴史上の7日シナリオ

入口プレミアム2%以上で、Aster買い1,000ドルを基準とする同数量の2脚を7日後Markで評価した。Funding、手数料、板による摩擦を除外し、窓は重複する。中央値や下位10%はこの限定モデルの記述統計であり、独立取引の勝率、実現損益、執行バックテストではない。
