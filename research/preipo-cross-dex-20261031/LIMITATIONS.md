# 未検証事項・保存状態

## 判定を制限する点

| 論点 | 現在の状態 | 必要な追加証拠 |
| --- | --- | --- |
| 契約の同一性 | 10億株という表示スケールのみ一致 | 株式クラス、希薄化範囲、最終倍率 |
| IPO・先行精算 | 通常市場への移行と先行精算可能性、他銘柄の実例あり | 対象銘柄ごとの数量・取得価・精算価格・時刻 |
| 長期乖離の原因 | 流動性非対称と内部価格機構を確認 | 株数変更の一次証拠、因果を識別する検証 |
| Funding | 条件付き率比較のみ | rate/direction/value/timestamp定義と精算Index/Mark |
| 口座の費用 | 公開手数料・metadataを使用 | 実口座tier、遅延・注文制限 |
| 注文受付 | 板・数量・最低額を検査、注文未送信 | Aster tradingMode=1の定義、動的価格制限 |
| 実行・保有リスク | 静的な板とMarkの計算 | 片側未約定、部分約定、清算、ADL、資金移動の影響 |
| 通貨 | USDTとUSD/USDC等価を仮定 | 通貨間乖離・交換/移動コスト |
| 出口シナリオ | 中値平均と現在摩擦を固定 | 将来の板と価格経路。シナリオは予測ではない |

Lighterの文書上の価格上限説明とAPIのMark capは、異なる層の可能性があり未解決。「完全に上限なし」とは扱わない。Lighter 3bpsの感応度をPremium口座の実料金とは呼ばない。

## 標本と統計

板は3標本で、応答窓が3.90〜11.17秒ある。原子的な同時刻の取得ではなく、入口・出口のすべてをその価格で受け付ける保証はない。1時間足やMarkは執行可能価格ではない。ゼロ出来高による持越しを除いても約定時刻は完全には同期しない。

7日Mark損益はFunding・手数料・深度を除外し、窓が重複する。中央値を利益期待値や将来勝率へ読み替えない。一定等額建玉のFunding率合計と、固定数量ポジションのキャッシュ損益を混同しない。

`f25f664e4a93e5ca2b81d8b455c12d1dca941a2e02fc3f672f305c5b774a7c0b`

このMarkdown群の数値は研究担当から受領した精査済み結果であり、ローカル再計算による独立検証が完了した結果ではない。30日Funding集計の厳密な時刻境界、全市場の取得期間、実列名も未転送資料への照合が残る。

## GitHubへの公開範囲

公開対象はこのディレクトリ直下のMarkdown 6ファイルだけ。価格系列、板、Excel、ZIP、スクリプト、ログ、転送情報、認証情報は含めない。`local-data/` と直下のMarkdown以外の内容はローカルの `.git/info/exclude` で除外する。ローカル除外は他のcloneには配布されないため、他環境でデータを保存する場合もstage対象を個別指定する必要がある。

ローカル専用の `local-data/SAVE_STATUS.json` に取得結果を記録した。既存の別研究の変更・未追跡ファイルは本作業のcommitに含めない。mainへの直接変更やマージは行わない。
